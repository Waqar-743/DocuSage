DocuSage 2.0.1 delivers major UI contrast & theme improvements, first-class Anthropic/OpenAI/Google Gemini provider management with live verification, deduplicated runtime notifications, and zero-config 1-click local GGUF model download, setup, and testing.

### UI Contrast & New Themes

- **Fixed Dark Mode Color Contrast & Visibility (#3):** Ensured all modals (`Settings`, `Command Palette`, `Model Compare`, `Shortcuts`), dropdowns, inputs, badges, citations, and active/selected elements inherit crisp high-contrast foreground colors and sync `color-scheme` cleanly with the active theme.
- **Added Cream & Navy Blue Themes (#4):** Introduced warm **Cream** and deep **Navy Blue** palettes alongside existing themes (`Obsidian Dark`, `Studio Light`, `Spotlight Glass`, `Warm Paper`, `Rose Quartz`, `Deep Ocean`) with visual color swatches in Settings → Appearance and instant switching without page refresh.

### AI Provider Management & Model Selector

- **Anthropic, OpenAI & Google Gemini Configuration (#5):** Added dedicated independent API key sections for Anthropic, OpenAI, and Google Gemini with masked inputs, Save/Update and Verify buttons, OS Keyring storage (never logged or written to JSON), and real authentication checks reporting `Verified`, `Invalid API Key`, `Connection Error`, or `Not Configured`.
- **Grouped Top-Left Model Selector (#5):** Upgraded the top-left model switcher to group models cleanly under Built-in Local (GGUF), Anthropic, OpenAI, and Google Gemini with human-readable model names, active indicators, and instant switching using each provider's stored credentials.

### Zero-Config Local AI & Notification Fixes

- **Deduplicated Runtime Notifications (#6):** Prevented repeated identical error toasts when clicking Load Chat or Load Embed without `llama-server` installed, displaying a single clear notification with a direct **Install Runtime** action button.
- **1-Click Local Model Download, Redirect & Live Testing:** Clicking **Download & Run** downloads directly into managed app storage (no local path prompts), redirects back to the chat workspace with a live progress banner, automatically installs `llama-server` if missing, loads the model, and provides a 1-click **Test Model** check with live response and latency reporting.
- **Local Runtime Stability:** Preferred zero-dependency Vulkan/CPU builds on Windows, added recursive `llama-server` discovery, configured `LD_LIBRARY_PATH`/`DYLD_LIBRARY_PATH` for bundled shared libraries, captured startup stderr diagnostics, and auto-started downloaded GGUF models on chat send.
