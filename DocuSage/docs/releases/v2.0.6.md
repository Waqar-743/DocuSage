DocuSage 2.0.6 delivers a cleaner chatbot startup experience, instant model-selector and settings dismissal when switching models, and refined marketing site polish.

### Clean Startup & Instant Model Switching

- **Clean Chatbot Startup:** Stopped saved partial downloads from auto-showing a paused-download banner on the main chat header at startup; resumable downloads remain cleanly accessible inside **Settings -> Offline models**. Also clears stale setup status banners when switching providers, connecting an offline model, or sending a message.
- **Immediate Model Selector Dismissal:** Closes the model dropdown immediately on selection or `Escape`, and marks the selector and backdrop with `data-no-drag` so clicking or dismissing it never triggers window-header dragging.
- **Auto-Dismiss Model Settings & Ready-State Cleanup:** Automatically closes Settings after selecting or loading an offline or cloud model so you land directly in chat, and hides empty-state onboarding setup cards once an offline or cloud model is ready.

### Regression Coverage & Documentation

- **UI Regression Tests:** Added automated tests verifying clean startup with saved partial downloads, immediate model selector dismissal, Settings auto-dismiss on model selection, and hidden setup cards once a model is ready.
- **Website & README Updates:** Polished website copy, visuals, SEO metadata, and refreshed verification screenshots and documentation for the clean startup and instant model switching behavior.
