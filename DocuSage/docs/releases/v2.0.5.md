DocuSage 2.0.5 polishes the desktop workspace UI, updates cloud and offline model catalogs to the latest generations, fixes theme contrast and dark-mode opacity, and adds instant whole-app transparency shortcuts.

### Interface & Usability Improvements

- **Clean Prompt Composer:** Removed the green focus border around the chat prompt input for a distraction-free writing experience.
- **Easy Conversation Deletion:** Made the delete button always visible on sidebar chat rows and added a 1-click **Delete conversation** button directly in both Dashboard and Spotlight headers.
- **3-Dot Model Loading Animation:** Added a smooth 3-dot loading indicator whenever an offline model is loading or an AI response is starting.
- **Updated Top-Left Branding & Quick Actions:** Replaced the green dot with the official DocuSage logo, removed the `v2` badge, and placed **New Chat**, **New Folder**, and **Document** right below the logo for effortless access.
- **Renamed to "Offline models":** Replaced "Local AI & GGUF" labels across Settings, the model switcher, and Command Palette with clear, user-friendly **Offline models** terminology.
- **1-Click Quick Start:** Added friendly Quick Start cards on empty chats so end users can download an offline model, add a cloud API key, or attach a document in one click.

### Latest Cloud & Ultra-Fast Offline Models

- **Updated Cloud AI Lineup:** Replaced outdated legacy models with the latest **Google Gemini** (`gemini-4-hydrogen`, `gemini-4-carbon`, `gemini-4-neon`, `gemini-4-argon`, `gemini-3.8-flash`, `gemini-3.5-flash-lite`), **OpenAI ChatGPT** (`gpt-6.2-sol`, `gpt-6.2-astra`, `gpt-6.1-terra`, `gpt-6-luna`, `gpt-5.2`), and **Anthropic Claude** (`claude-sonnet-5-5`, `claude-opus-5-5`, `claude-haiku-5-5`, `claude-fable-5-2`, `claude-sonnet-4-6`, `claude-opus-4-6`).
- **Smallest & Fastest Offline Models:** Added compact, instant-download GGUF models starting at **229 MB**: **LFM 2 350M**, **Gemma 3 270M**, **SmolLM2 360M Instruct**, **Qwen 3 0.6B**, and **Gemma 3 1B**.

### Window Controls, Themes & Transparency

- **Disabled Header Double-Click Fullscreen/Maximize:** Removed the accidental double-click window toggle and native drag-region double-click maximize while preserving smooth single-click window dragging.
- **Solid Dark Modes & Fixed Theme Contrast:** Eliminated unintended background transparency in dark mode (`Graphite Dark` replaces translucent `Spotlight Glass`), fixed colliding CSS overrides on selected Appearance cards, and harmonized accent tokens across all 8 themes.
- **Whole-App Transparency Shortcuts:** Added `Shift + -` (increase transparency) and `Shift + +` (decrease transparency) — plus `Ctrl + Shift + +/-` while typing — and a matching **Window Transparency** slider in **Settings -> Appearance**.
