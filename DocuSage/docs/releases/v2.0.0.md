DocuSage 2.0.0 is a ground-up optimization and architecture redesign focused on ultra-lightweight installers (<10 MB), true offline and online AI with hybrid RAG, and a fast cursor-summoned Spotlight + Dashboard desktop experience.

### Ultra-lightweight installers (<10 MB target)

- Removed heavy embedded ML/vector dependencies (`lancedb`, `arrow-*`, `lzma-sys`, `mistralrs`, `fastembed`) in favor of an embedded SQLite (`rusqlite` with FTS5) store and an on-demand `llama-server` sidecar.
- Decoupled the marketing website (`MarketingSite.tsx`, `MarketingSite.css`, `public/media/*`) from the desktop Tauri bundle via a dedicated `build:desktop` Vite mode (~380 KB desktop frontend assets).
- Optimized release builds with `opt-level = "z"`, fat LTO, single codegen unit, and stripped binaries.

### Hybrid SQLite RAG & Multi-Format Ingestion

- Local `vectors.db` (WAL mode) combining instant zero-dependency SQLite FTS5 BM25 keyword search with in-Rust cosine similarity merged via Reciprocal Rank Fusion (RRF), with per-chunk `embedding_model` tracking.
- Multi-format document pipeline supporting 36 document, markup, code, and config extensions (`pdf`, `txt`, `md`, `html`, `py`, `ts`, `rs`, `json`, `yaml`, `sql`, `csv`, etc.) up to 50 MB with path-traversal checks and `(mtime, size)` text caching.
- Always-on Smart Context routing: automatically injects small documents (<= 12,000 chars) verbatim (`Full Context`), switches larger documents to `Hybrid RAG` or `FTS5 Offline` within a configurable token budget, and exposes live context badges, token estimates, and expandable citations.

### True Offline & Online Streaming AI

- On-demand `llama-server` sidecar installer (auto-detects OS/arch and CUDA/Vulkan/Metal/CPU with SHA256 verification), ephemeral localhost port management, hot-swappable `.gguf` chat and embedding models, and clean process shutdown on exit.
- Unified SSE/NDJSON streaming with instant `CancellationToken` cancellation and dynamic "Verify & Fetch Models" across Built-in Local GGUF, Ollama, LM Studio, Google Gemini, OpenAI, Anthropic Claude, OpenRouter, and Custom OpenAI-compatible providers. API keys remain exclusively in the OS keyring.
- Pluggable embedding backends (`llama-server`, Ollama, Gemini `gemini-embedding-001`, OpenAI-compatible) with automatic zero-error fallback to FTS5 offline search.

### Spotlight + Dashboard UX & Modular Frontend

- Cursor-summoned floating Spotlight window (`440x560`, multi-monitor clamped, auto-hide on focus loss unless pinned/dialog/settings open) paired with a full Dashboard workspace (`1140x760`, remembers bounds and maximized state), system tray, and `--hidden` OS autostart.
- Modular React 19 + TypeScript + Tailwind 4 + Zustand architecture with Command Palette (`Ctrl+K`), Clipboard Quote (`Ctrl+Shift+V`), Side-by-Side Model Compare (2–4 models), Conversation Branching, Folders, Full-Text Chat Search, Smart Context Inspector, and JSON/Markdown Backup.
- Automatic v1-to-v2 chat migration preserving existing conversations and `Documents/DocuSage/models` discovery.
