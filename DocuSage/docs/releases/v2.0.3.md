DocuSage 2.0.3 replaces the external `llama-server` sidecar with a built-in in-process `llama.cpp` inference engine (Neurix architecture), adds the full Neurix local GGUF model catalog with clickable specification details, and introduces live resumable download telemetry.

### Built-in In-Process Local AI Engine

- **Eliminated `0xc0000005` `llama-server` Startup Crashes:** Local GGUF inference now runs directly inside DocuSage via `llama-cpp-2` (`v0.1.159`), removing external `llama-server.exe` binary downloads, localhost port management, and Windows Vulkan DLL initialization crashes.
- **Native Chat Templates & Streaming:** Renders each GGUF's embedded Jinja2 chat template via `minijinja`, with UTF-8 token reassembly, reasoning tag filtering, KV-cache prefix reuse, and automatic RAM/CPU thread sizing.

### Neurix Model Store, Model Details & Live Download Telemetry

- **Complete Neurix GGUF Model Catalog:** Added all current and specialist Neurix models (Qwen 3.5 0.8B / 2B / 4B, LFM 2.5 1.2B / 2.6B, Gemma 4 E2B / E4B, plus specialist fine-tunes and legacy models) with category filters (`All`, `Tiny`, `Fast`, `Balanced`, `Smart`, `Specialist`, `Legacy`), search, and automatic device RAM fit recommendations.
- **Clickable Model Details View:** Clicking any model opens a full detail view displaying publisher, parameters, quantization, memory needed vs. device RAM, context window, reasoning mode, download size, release date, HuggingFace repo, and SHA-256 checksum.
- **Resumable Downloads with Live Telemetry:** Downloads now support HTTP Range resume, pause/cancel, live download speed (`MB/s`), ETA, exact `downloaded / total` bytes, percentage progress, GGUF magic header checks, and SHA-256 checksum verification.
